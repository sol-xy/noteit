Install as iOS App (PWA)

In Safari on your iPhone, tap Share → Add to Home Screen to install NoteIt as a standalone app with offline reading and foreground recording.

Voice Memos + Action Button Shortcut

For locked-screen or hands-free meetings, map your iPhone Action Button to Voice Memo and create a Share Sheet Shortcut posting to:

  1. Open Apple Shortcuts → + → enable Show in Share Sheet (Audio / Files).
  2. Add action Get Contents of URL with the URL above and Method POST.
  3. Add Header: Authorization = Bearer <AUTH_TOKEN>.
  4. Set Request Body to Form with field file (type File) = Shortcut Input (optional title text field).
  5. After recording in Voice Memos, tap Share → your Shortcut to transcribe and summarize.
